# Intro Animation Concept

## Главная задача

Полностью изменить входную анимацию приложения до неузнаваемости.

Важно:
изменить именно входную анимацию, а не весь дизайн приложения.

---

# Концепция

Нужна премиальная стартовая анимация для Kinetix / Такси Партнер.

Анимация должна ощущаться как запуск современного такси-сервиса:

- быстро;
- чисто;
- технологично;
- премиально;
- без колхозности;
- без дешевых эффектов;
- без копирования Uber или Yandex Go.

---

# Идея анимации

Можно использовать такую структуру:

1. Темный или чистый премиальный фон.
2. Плавное появление световой линии маршрута.
3. Появление точки/маркера как символа заказа.
4. Легкий импульс вокруг маркера.
5. Появление названия Kinetix / Такси Партнер.
6. Короткий слоган.
7. Плавный переход к основному экрану.

---

# Визуальные элементы

Можно использовать:

- линию маршрута;
- точку подачи;
- точку назначения;
- легкое свечение;
- плавный масштаб;
- fade-in;
- slide-up;
- stagger animation;
- аккуратный pulse effect;
- карточку или нижнюю панель, которая появляется в конце.

---

# Что запрещено

- Не менять весь дизайн приложения.
- Не переписывать навигацию без необходимости.
- Не менять backend.
- Не менять бизнес-логику.
- Не добавлять тяжелые библиотеки без необходимости.
- Не делать мультяшный стиль.
- Не делать дешевые taxi-клише.
- Не использовать чужие логотипы.
- Не копировать Uber или Yandex Go один в один.

---

# Технический подход

Сначала использовать стандартные возможности React Native:

- Animated
- Easing
- Animated.sequence
- Animated.parallel
- Animated.stagger

Новую библиотеку добавлять только если без нее невозможно сделать нормальный результат.

---

# Ожидаемый результат

При входе в приложение пользователь должен увидеть новую премиальную анимацию, которая сильно отличается от текущей.

Она должна создавать ощущение:

"Это не просто заготовка, а современный локальный сервис такси и доставки".
