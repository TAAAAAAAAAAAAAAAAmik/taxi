2026-07-03 (Claude) — рефералка / оплата бонусами
- Кошелёк на ledger: FIFO-погашение обязано идти до проверки expiry, иначе истечение старого кредита «воскрешает» уже потраченные бонусы. Порядок: сортировка кредитов по createdAt → гашение долга → остаток учитывается только если не истёк.
- Дедуп начислений по (userId, sourceType, sourceId) без текста причины — иначе авто-начисление и админское подтверждение с разными reason создают двойную выплату.
- Тумблер бонусов встал внутрь существующего orderPriceCard как третья строка (чекбокс 18px + текст), а не отдельной карточкой: ценник остаётся единственным местом правды о цене, CTA пересчитывается тем же bonusDiscount.
- Для QA статического билда на localhost демо-режим включается через page.addInitScript с globalThis.process.env.EXPO_PUBLIC_ENABLE_DEMO='true' — getPublicEnv читает runtime-process раньше вшитого env.
