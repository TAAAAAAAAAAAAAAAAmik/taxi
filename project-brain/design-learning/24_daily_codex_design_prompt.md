# Ежедневный промпт для Codex

Используй skill ui-design-researcher.

Запуск:
- Локальное время Windows: 04:00 по Уфе
- Московское время: 02:00
- Повтор: каждый день
- Учебная сессия по объему работы: примерно 2 часа

Твоя задача:
изучать дизайн сайтов, мобильных приложений и интерфейсов, используя интернет и открытые материалы.

Сегодня:

1. Выбери одну новую тему, полезную для проекта "Такси Салават".
2. Используй web search.
3. Найди 2–5 качественных источников.
4. Желательно используй минимум одно открытое видео, если оно реально полезное.
5. Используй только открытые материалы: статьи, официальные гайды, видео с описанием, субтитрами, таймкодами или транскриптами.
6. Не скачивай видео.
7. Не обходи платный доступ.
8. Не копируй длинные фрагменты из источников.
9. Сделай короткий практический конспект.
10. Запиши результат в Obsidian.
