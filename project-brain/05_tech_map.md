# Техническая карта проекта

## Текущий тип проекта

Мобильное приложение на Expo / React Native.

## Основные части

- frontend приложения;
- экраны клиента;
- экраны водителя;
- будущая админ-панель;
- backend;
- база данных;
- документы;
- сборка APK.

## Важные файлы и папки

- App.tsx — входная точка приложения.
- src/ — основной код приложения.
- assets/ — изображения и ресурсы.
- docs/ — документы.
- project-brain/ — база знаний проекта для Obsidian и Codex.
- package.json — зависимости и команды проекта.

## Главный технический приоритет

Сначала проверить рабочий путь:

клиент создает заказ → водитель видит заказ → водитель принимает заказ → статус меняется → заказ завершается.

## Что нельзя делать рано

Пока MVP не стабилен, не нужно:
- подключать реальные карты;
- подключать реальные платежи;
- делать сложную CRM;
- делать сложную аналитику;
- полностью переписывать проект.
