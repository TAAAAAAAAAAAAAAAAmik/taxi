# Release Runbook

## Назначение

Этот файл нужен, чтобы перед сборкой APK не забывать важные проверки.

---

# Перед сборкой

Проверить:

- проект запускается
- нет критических ошибок
- главный MVP-сценарий работает
- клиент может создать заказ
- водитель может увидеть заказ
- водитель может принять заказ
- статус заказа меняется
- основные экраны открываются

---

# Проверка TypeScript

Запустить проверку, если команда есть в проекте:

npm run typecheck

Если такой команды нет, проверить package.json и использовать доступные команды.

---

# Проверка приложения

Проверить на телефоне:

- главный экран
- вход
- регистрация
- кабинет клиента
- создание заказа
- статус заказа
- кабинет водителя
- список заказов
- подписка водителя
- история заказов

---

# Перед APK

Проверить:

- app.config.js
- package name
- название приложения
- иконку
- splash screen
- ссылки на документы
- demo/prod режим
- API URL

---

# После APK

1. Установить APK на телефон.
2. Проверить все главные экраны.
3. Проверить читаемость текста.
4. Проверить кнопки.
5. Проверить главный MVP-сценарий.
6. Все ошибки записать в project-brain/07_bugs.md.
