# Текущая задача для Codex

## задача

проанализировать главный MVP-сценарий приложения:

клиент создает заказ → водитель видит заказ → водитель принимает заказ → статус меняется → заказ завершается.

## что нужно получить

Codex должен ответить на русском языке:

1. какие файлы отвечают за создание заказа.
2. какие файлы отвечают за кабинет водителя.
3. где хранятся заказы.
4. как сейчас меняется статус заказа.
5. чего не хватает для рабочего MVP.
6. какие 3 маленькие задачи нужно сделать первыми.

## ограничения

- код пока не менять.
- новый проект не создавать.
- архитектуру не переписывать.
- работать только с текущим проектом.
