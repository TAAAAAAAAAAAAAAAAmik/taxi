# главная база проекта

проект: Такси Партнер / Kinetix

Это локальное приложение такси и доставки для Салаватского района.

главная идея:
клиент создает заказ, водитель видит заказ, принимает его и выполняет поездку напрямую.

главная бизнес-модель:
- водитель может платить подписку в месяц;
- либо работать по проценту с заказа.

основные роли:
- клиент;
- водитель;
- администратор;
- в будущем маркетолог / агент привлечения.

главный MVP-сценарий:
клиент создал заказ → водитель увидел заказ → водитель принял заказ → статус изменился → заказ завершился.

главное правило:
не раздувать проект сразу. Идти от малого к большему.
