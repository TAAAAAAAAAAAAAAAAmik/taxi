# Codex Roles

## Назначение

Этот файл нужен, чтобы Codex мог работать как команда из разных ролей, но не смешивал задачи в одну кучу.

---

# Frontend Agent

Отвечает за:

- экраны
- навигацию
- внешний вид
- адаптацию под телефон
- читаемость
- кнопки
- формы

Главное правило:

не трогать backend без необходимости.

---

# Backend Agent

Отвечает за:

- API
- хранение данных
- авторизацию
- заказы
- водителей
- статусы заказов
- подписки

Главное правило:

не менять дизайн и экраны без необходимости.

---

# QA Agent

Отвечает за:

- поиск багов
- проверку сценариев
- ошибки сборки
- тестовые шаги
- проверку после изменений

Главное правило:

сначала найти проблему, потом предлагать исправление.

---

# Product Agent

Отвечает за:

- бизнес-логику
- MVP
- монетизацию
- простоту продукта
- защиту проекта от лишних функций

Главное правило:

не давать проекту раздуваться раньше времени.

---

# Главное правило для всех ролей

Не запускать всех агентов сразу без необходимости.

Сначала одна маленькая задача.
Потом проверка.
Потом следующая задача.

# Использование навыков

Если задача связана с интерфейсом, дизайном или текстами:

- читать [[22_codex_skill_taxi_ui_ux]];
- после реализации читать [[23_codex_skill_visual_qa]].

Перед началом любой значимой задачи и после ее завершения:

- читать [[24_codex_skill_project_memory]].

Навыки не заменяют роли.

Роль определяет, кто выполняет задачу.
Навык определяет, как именно задача должна быть выполнена.

---

# Передача в команде Claude + Codex

Codex и Claude работают как одна команда. Полный регламент — [[25_team_protocol]].

Короткое правило разделения:

- Codex набрасывает черновик и инфраструктуру (каркасы экранов, `scripts/`, конфиги, билд, smoke-тесты, механические правки).
- Claude принимает черновик и доводит архитектуру, бизнес-логику и дизайн, после чего делает ревью.
- Финальную вычитку может делать второй движок: `codex exec review` ⇄ Claude `/code-review`.

После черновика Codex обновляет `09_last_state.md` и `codex_learning_log.txt`, чтобы Claude мог продолжить без повторного анализа всего проекта.

Инструкция Claude как участника команды — в `CLAUDE.md` (симметрична `AGENTS.md`).
