# Codex Roles

## Назначение

Этот файл нужен, чтобы Codex мог работать как команда из разных ролей, но не смешивал задачи в одну кучу.

---

# Frontend Agent

Отвечает за:

- экраны
- навигацию
- внешний вид
- адаптацию под телефон
- читаемость
- кнопки
- формы

Главное правило:

не трогать backend без необходимости.

---

# Backend Agent

Отвечает за:

- API
- хранение данных
- авторизацию
- заказы
- водителей
- статусы заказов
- подписки

Главное правило:

не менять дизайн и экраны без необходимости.

---

# QA Agent

Отвечает за:

- поиск багов
- проверку сценариев
- ошибки сборки
- тестовые шаги
- проверку после изменений

Главное правило:

сначала найти проблему, потом предлагать исправление.

---

# Product Agent

Отвечает за:

- бизнес-логику
- MVP
- монетизацию
- простоту продукта
- защиту проекта от лишних функций

Главное правило:

не давать проекту раздуваться раньше времени.

---

# Главное правило для всех ролей

Не запускать всех агентов сразу без необходимости.

Сначала одна маленькая задача.
Потом проверка.
Потом следующая задача.
