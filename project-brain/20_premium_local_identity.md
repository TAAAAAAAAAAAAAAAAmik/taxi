# Premium Local Identity

## Главная мысль

Локальность проекта не должна выглядеть колхозно.

Мы делаем не деревенское приложение, а современный локальный сервис такси и доставки.

Правильная формула:

премиальный цифровой сервис + знание местных маршрутов + простота для обычного пользователя.

---

# Что значит "локально, но не колхозно"

## Правильно

- чистый интерфейс
- крупные аккуратные кнопки
- понятные карточки
- современные отступы
- спокойные цвета
- уверенный текст
- быстрые действия
- минимум лишних украшений
- ощущение надежного сервиса

## Неправильно

- слишком много желтого
- дешевые иконки машин
- перегруженные баннеры
- кричащие надписи
- деревенские клише
- много эмодзи
- случайные цвета
- мелкий текст
- устаревший вид
- ощущение самодельного приложения

---

# Как показывать локальность

Локальность нужно показывать не через колхозный стиль, а через пользу.

## Хорошие способы

- быстрые популярные маршруты
- знакомые населенные пункты
- понятные условия для водителей
- локальная поддержка
- поездки между селами и точками района
- простая доставка по району

## Примеры

Вместо:
"Такси по деревне"

Лучше:
"Быстрые поездки по району"

Вместо:
"Наши местные водители"

Лучше:
"Проверенные водители рядом"

Вместо:
"Дешево довезем"

Лучше:
"Понятная цена до поездки"

Вместо:
"Районное такси"

Лучше:
"Такси и доставка для Салаватского района"

---

# Визуальный стиль

Стиль должен быть:

- современный
- чистый
- уверенный
- технологичный
- спокойный
- премиальный
- без лишнего пафоса
- без ощущения дешевой поделки

## Цвета

Можно использовать:

- темно-серый
- черный
- белый
- мягкий желтый акцент
- синий технологичный акцент
- нейтральные серые оттенки

Не нужно использовать слишком кислотные цвета.

## Компоненты

Использовать:

- карточки
- нижние панели
- крупные CTA-кнопки
- понятные статусы
- аккуратные бейджи
- простые формы
- единый стиль иконок

---

# Уникальность Kinetix / Такси Партнер

Главная изюминка:

это не копия Uber и не копия Yandex Go.

Это современный сервис, который понимает район лучше больших агрегаторов.

Ключевые отличия:

1. Быстрые локальные маршруты.
2. Простые поездки между населенными пунктами.
3. Такси и доставка в одном месте.
4. Честные условия для водителей.
5. Понятный интерфейс без лишней сложности.
6. Ощущение надежного местного сервиса, а не случайного приложения.

---

# Правило для Codex

Если Codex делает дизайн, тексты или интерфейс, он должен соблюдать правило:

локальность должна выглядеть премиально, а не колхозно.

Нельзя превращать приложение в дешевую копию такси-сервиса.

Нужно делать продукт, который выглядит как современный сервис для реальных людей в районе.
