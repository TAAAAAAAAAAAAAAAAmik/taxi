# Правила экономии лимитов Codex

## главная идея

не заставлять Codex каждый раз читать весь проект и всю базу знаний.

## как экономить лимиты

1. для каждой задачи использовать короткий промпт.
2. не вставлять длинные ТЗ в чат вручную.
3. Хранить ТЗ в Markdown-файлах.
4. перед задачей указывать, какие файлы читать.
5. не просить Codex анализировать весь проект без необходимости.
6. делать одну маленькую задачу за раз.
7. после задачи обновлять 09_last_state.md.
8. если задача про MVP, читать только MVP-файлы.
9. если задача про монетизацию, читать только monetization-файлы.
10. если задача про баг, читать 07_bugs.md и конкретные файлы ошибки.

## плохой запрос

Сделай всё приложение такси, добавь админку, оплату, карты, дизайн и сервер.

## Хороший запрос

прочитай AGENTS.md, project-brain/09_last_state.md и project-brain/10_current_task.md.
выполни только текущую задачу.
не меняй код без плана.
ответь на русском.
