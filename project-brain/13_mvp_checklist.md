# MVP Checklist

## Главный сценарий

- [ ] Клиент может создать заказ
- [ ] Заказ сохраняется
- [ ] Водитель видит доступные заказы
- [ ] Водитель может принять заказ
- [ ] Статус заказа меняется
- [ ] Клиент видит новый статус
- [ ] Заказ можно завершить
- [ ] История заказов сохраняется

## Минимальный рабочий путь

MVP считается рабочим, если можно показать путь:

клиент создал заказ -> водитель увидел заказ -> водитель принял заказ -> статус изменился -> заказ завершился.

## Что не входит в первый MVP

- Реальные карты
- Автоматические платежи
- Большая админ-панель
- Сложная аналитика
- Автоматические выплаты водителям

## Критерий готовности

Приложение можно показать водителю и объяснить:

"Вот клиент создает заказ, а ты видишь его и можешь принять".
