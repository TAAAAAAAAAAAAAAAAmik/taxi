# Роли в проекте

## Клиент

Клиент использует приложение, чтобы заказать поездку или доставку.

Клиент должен уметь:
- выбрать адрес подачи;
- выбрать адрес назначения;
- указать телефон;
- добавить комментарий;
- выбрать тип заказа: такси или доставка;
- видеть статус заказа;
- видеть историю заказов;
- связаться с водителем или поддержкой.

## Водитель

Водитель получает заказы через приложение и выполняет их.

Водитель должен уметь:
- зарегистрироваться;
- пройти подтверждение;
- выбрать модель работы;
- видеть доступные заказы;
- принимать заказ;
- менять статус заказа;
- видеть текущий заказ;
- видеть историю заказов;
- видеть свой доход.

## Администратор

Администратор управляет системой.

Администратор должен уметь:
- видеть все заказы;
- видеть всех водителей;
- подтверждать водителей;
- блокировать водителей;
- менять тарифы;
- подтверждать оплату;
- смотреть статистику.

## Маркетолог / агент

Эта роль нужна позже.

Маркетолог может:
- привлекать водителей;
- привлекать клиентов;
- договариваться с магазинами и аптеками о рекламе;
- получать вознаграждение за результат.
