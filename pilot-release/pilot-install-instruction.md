# Kinetix closed pilot install

Отсканируйте QR-код с Android-телефона, скачайте APK и установите приложение Kinetix.

Если телефон попросит разрешить установку из неизвестных источников - разрешите установку для браузера или файлового менеджера.

## Для администратора пилота

1. Загрузить `kinetix-pilot-v1.apk` на Google Drive.
2. Открыть доступ: "Все, у кого есть ссылка" -> "Читатель".
3. Скопировать ссылку на файл.
4. Создать QR-код именно на Google Drive-ссылку, не на локальный файл.
5. Сохранить QR-код рядом с APK под именем `kinetix-apk-qr.png`.
6. Проверить QR с Android-телефона: ссылка открывается, APK скачивается, приложение устанавливается и запускается.

APK не публиковать в Play Market / App Store и не размещать в открытом доступе.
